## 🎯 Mission

既存の教育や学習ツールの「壁」を打ち破り、学ぶこと自体を楽しい冒険に変えるプロダクト群を開発しています。
**"Enludus"** は "Enlightenment (啓蒙)" + "Ludus (遊び)" を掛け合わせた造語です。
